📌 ЧТО ЭТО ЗА ПРОГРАММА?

ENT Webhook Tester — это простой инструмент для проверки настройки 
HTTP-интеграции (вебхуков) в ПО «ЭНТ Контроль доступа».

Программа имитирует принимающий сервер (например, Битрикс24 
или AmoCRM) на вашем компьютере. Это позволяет убедиться, 
что «ЭНТ Сервер» корректно отправляет уведомления о событиях 
(проходы, тревоги и т.д.), прежде чем настраивать реальную 
интеграцию с облачным сервисом.

Программа работает полностью на вашем компьютере и не 
отправляет никакие данные в интернет.


📦 УСТАНОВКА

Установка не требуется! 

1. Скопируйте файл ENT_Webhook_Tester.exe в любую удобную 
   папку на компьютере (например, на Рабочий стол или в 
   папку C:\ENT_Tester).

2. Готово. Никаких дополнительных программ устанавливать 
   не нужно.


🚀 ЗАПУСК

1. Дважды кликните по файлу ENT_Webhook_Tester.exe.
2. Автоматически откроется веб-интерфейс в вашем браузере.
3. В правом нижнем углу экрана (в системном трее, рядом с 
   часами) появится значок программы.

Примечание: при первом запуске Windows может показать 
предупреждение «Защитник Windows предотвратил запуск...». 
Это нормально, так как программа не подписана цифровым 
сертификатом. Нажмите «Подробнее» → «Выполнить в любом 
случае».

Примечание: при запуске брандмауэр Windows может 
запросить разрешение на доступ к сети. Нажмите «Разрешить».


🖥 КАК ПОЛЬЗОВАТЬСЯ

После запуска в браузере, который установлен по умолчанию,
автоматически откроется веб-интерфейс сервиса с основными элементами:

  • Порт — номер порта, на котором программа принимает 
    запросы (по умолчанию 8080).
  • URL для вебхука — адрес, который нужно указать во 
    внешней системе. Например: http://localhost:8080
  • Журнал запросов — таблица, в которой отображаются все 
    входящие вебхуки с их содержимым.

──────────────
В веб-интерфейсе на вкладке «Настройки»:

1. 🔀 СМЕНА ПОРТА

   По умолчанию: 8080. Если этот порт занят другой 
   программой, вы можете сменить его:
    1. Введите новый номер порта в поле «Порт» (например, 9090).
    2. Появится надпись «Требует перезапуска» с кнопкой 
    «⏹️ Остановить сейчас».
    3. Нажмите эту кнопку.
    4. Программа остановится. Закройте вкладку браузера, если
    она не закрылась автоматически.
    5. Снова запустите ENT_Webhook_Tester.exe двойным кликом.
    6. Программа запустится на новом порту.

2. 🗣️ РЕЖИМ ОТВЕТА

   Выберите, как программа должна отвечать на запросы:
   • Успешный ответ (200 OK) — стандартный режим, имитирует 
     успешное получение данных
   • Ошибка сервера (500) — для проверки механизма повторных 
     отправок (ретраев) в ЭНТ Сервере
   • Редирект (301) — для проверки поведения при перенаправлении
   • Зависание (Таймаут) — имитирует «зависший» сервер (35 сек)

3. 🆗 ТИП ОТВЕТА (для режима 200 OK)

   • Битрикс24 (JSON) — возвращает {"STATUS":"OPENED"}
   • AmoCRM (Текст) — возвращает "success"
   • Универсальный — возвращает "OK"
   • Свой текст — можно написать любой ответ вручную

4. 🗝️ ТОКЕН

   Укажите секретный ключ, который вы прописали в URL 
   вебхука в настройках ЭНТ Клиента. Программа будет 
   проверять его совпадение и подсвечивать результат 
   в журнале.

──────────────
В веб-интерфейсе на вкладке «Журнал»:

📋 ПРОСМОТР ЖУРНАЛА

Все входящие вебхуки автоматически записываются в журнал:

  • Дата и время получения запроса
  • Метод (GET, POST и т.д.)
  • Заголовки запроса
  • Тело запроса (данные, которые отправила внешняя система)

Журнал обновляется автоматически каждые несколько секунд.

⚙️ КАК ПРОВЕРИТЬ, ЧТО ВСЁ РАБОТАЕТ?

1. Скопируйте URL из блока «URL для настройки СКУД» 
   (кнопка «Копировать»)

2. Вставьте этот URL в настройках «ЭНТ Клиента»:
   События → Рассылка уведомлений → Добавить новое 
   уведомление → поле «Текст SMS уведомления»

3. Создайте тестовое событие (например, приложите карту 
   к считывателю контроллера «ЭРА»)

4. Перейдите на вкладку «Журнал» в веб-интерфейсе 
   тестера — запрос должен появиться в таблице в течение 
   2 секунд

5. Проверьте:
   • Статус токена (зелёный ✅ = совпал, красный ❌ = ошибка)
   • Переданные данные (макросы <%dv>, <%te>, <%ln> и др.)
   • User-Agent (должен содержать "Synapse")

⏹ ОСТАНОВКА ПРОГРАММЫ

Способ 1 — Через веб-интерфейс:
  1. Нажмите кнопку «⏹️ Остановить сейчас» рядом с 
     надписью «Требует перезапуска» (появляется после 
     смены порта).
  2. Подтвердите остановку.
  3. Закройте вкладку браузера, если она осталась открытой.

Способ 2 — Через системный трей:
  1. Найдите значок программы в правом нижнем углу экрана 
     (рядом с часами). Возможно, нужно нажать на стрелочку 
     «^», чтобы показать скрытые значки.
  2. Кликните по значку правой кнопкой мыши.
  3. Выберите «❌ Выход».
  4. Закройте вкладку браузера вручную.

❓ ЧАСТЫЕ ПРОБЛЕМЫ И ВОПРОСЫ

Программа не запускается.
    Убедитесь, что вы не запускаете её из архива (ZIP/RAR). 
    Сначала распакуйте файл .exe в обычную папку.

Браузер не открывается автоматически.
    Откройте браузер вручную и введите в адресную строку 
    адрес, указанный в программе (например, http://localhost:8080).

«Порт занят» / сервер не запускается.
    Закройте другие программы, использующие порт 8080
    (Skype, торренты, другие веб-серверы), или укажите другой порт в настройках.

Вебхуки не приходят.
    → Убедитесь, что в настройках «ЭНТ Сервера» в разделе 
     «SMS-шлюз» выбран провайдер «HTTP(S)-запрос».
    → Проверьте, что URL в настройках уведомления совпадает 
     с URL, указанным в тестере (включая порт и токен).
    → Убедитесь, что брандмауэр Windows не блокирует входящие соединения
    на указанный порт.

Антивирус блокирует запуск и ругается на программу.
    Это ложное срабатывание. Программа безопасна, не содержит вредоносного кода
    и работает только на вашем компьютере.
    Добавьте файл ENT_Webhook_Tester.exe в исключения антивируса.

В журнале видны запросы, но «ЭНТ Сервер» уходит в ретраи.
    Некоректный ответ от сервиса.
    Замените в тестере ответ на «Успешный 
     ответ (200 OK)». Проверте получение ответа.

В: Можно ли закрыть вкладку браузера?
О: Да, программа продолжит работать в фоне (значок в трее 
   останется). Чтобы снова открыть интерфейс, кликните 
   правой кнопкой мыши по значку в трее и выберите 
   «🌐 Открыть веб-интерфейс».

📝 ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ
──────────────────────
• Программа работает локально (127.0.0.1) и не передаёт 
  данные в интернет.
• Настройки сохраняются в файл config.json рядом с 
  программой и запоминаются между запусками.
• Журнал хранит последние 100 запросов и очищается при 
  закрытии программы.
• Исходящие запросы от ЭНТ Сервера имеют заголовок 
  User-Agent: Mozilla/4.0 (compatible; Synapse)
